# Catalogue des projets publics

Le catalogue utilise une liste éditoriale dans `public/projets.json`. La priorité correspond à l’ordre de présentation en entretien. La taille décrit le périmètre du projet. Pour ajouter ou modifier une entrée, mettre à jour ce fichier et la version Markdown [PROJETS.md](../PROJETS.md).

Les liens ouvrent soit une démo utilisable sans compte, soit le support indiqué. Les captures des trois projets mis en avant se trouvent dans `public/images/`.

Pour publier le catalogue, exécuter `npx wrangler deploy` dans ce dossier. Le catalogue est hébergé sur [Cloudflare Workers](https://baalla-projets.abdelhakimbaalla50.workers.dev/).
